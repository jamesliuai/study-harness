# Privacy and provider choices

Study Harness stores study work locally. It has no account, cloud sync, analytics service, remote file crawler, or automatic model requests. Opening a source, typing, moving a visual control, and scheduling a review do not contact a provider. The offline development app cannot read credentials, construct a provider, upload audio, or incur a charge. Its database and simulation labels remain separate from production.

The normal app uses the existing OpenAI adapter. When you explicitly request support it sends the current saved response, frozen task/reference/rubric, up to three recent help excerpts (bounded to 2,000 UTF-8 bytes each), and at most five source passages. Context is bounded to 32,000 encoded bytes before reservation. Full history, credentials, the review queue, and held-out comparison questions are not sent as a conversation archive. Source passages are untrusted content; their instructions do not grant native permissions. A validated citation proves a quote came from a captured passage, not that its mathematical claim is correct.

Audio stays in renderer memory. Recording is optional, limited to 120 seconds, and normalized to mono PCM WAV at 16 kHz. Transcription uploads only after you choose it. Raw audio is released on successful transcription, discard, activity change, or exit. Settings can also discard it after failed transcription. The default allows retry after failure. Original recognized text and confirmed edits remain local evidence until the session is intentionally deleted. No recording archive is exported.

API keys are held in Rust memory or saved explicitly in macOS Keychain. There is no renderer command to retrieve a saved key. A masked status is shown. `--no-keychain` launches with saved-key access disabled and supports session-only setup. The ordinary launch keeps the established Keychain behavior. Keys never enter SQLite, source retrieval, portable archives, backups, logs, or the comparison export. API billing is separate from ChatGPT subscriptions.

The Responses request uses `store:false`; this is not a claim of zero provider retention. Provider policies, account controls, model access, rates and speech quality require later live acceptance. The app's versioned rate table is an estimate, not a provider billing guarantee. Defaults remain $1 per session and $10 per UTC calendar month. Pending requests and unknown charges retain conservative reservations; cancelled, malformed, rejected, and stale responses can still cost money. Limits cover this local profile. Other profiles and other uses of the same key have separate spending. Settings show recorded costs and allow smaller or larger limits.

Sources retain original selected bytes, SHA-256, extraction version, and page/section anchors. Text PDF extraction runs in a bundled local worker. No OCR is implemented. Fractions, superscripts and reading order can be wrong; compare the original page or paste a verified transcription. PDF scripts, embedded actions, attachments, and imported HTML are not executed or mounted as application UI.

Portable archives and pre-migration SQLite backups contain private study text and sources. They are unencrypted files with restrictive local permissions. Choose a protected backup for sensitive storage or transfers. Protected backups use a passphrase, random salt/nonce, PBKDF2-HMAC-SHA256 and AES-256-GCM. Losing the passphrase loses access; the app has no recovery service. Protect exported comparison files too: they include held-out questions, reference solutions and user-entered scores.

Intentional deletion removes associated attempts, assessments, summaries, reviews, requests, usage, citations, visual artifacts and relevant comparison pairs. Deleting a source conservatively deletes sessions that used or viewed it, plus every session in a goal with that source attached. This also removes the shared plan, preventing retained quotes and misleading evidence. The preview states the scope and requires typing DELETE. App-managed migration backups are removed too. Copies you previously exported elsewhere, provider-held data, filesystem snapshots and OS backups remain under your control; app deletion is not a promise of forensic erasure.
